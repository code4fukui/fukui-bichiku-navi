# 福井備蓄ナビ（備蓄ナビえちぜん）

福井備蓄ナビは、福井県越前市向けに、家族構成や年齢・性別に基づいたパーソナライズされた緊急備蓄情報を提供する災害対策ウェブサイトです。東京都のオープンソースプロジェクト「東京備蓄ナビ」を基盤としており、デジタル資源の共有を通じた自治体間の連携を示す好例となっています。

## デモ

**[https://bichikunavi.code4fukui.org/](https://bichikunavi.code4fukui.org/)**

## 機能

- **パーソナライズされた推奨リスト**: 家族の人数、年齢、性別に基づいて、1週間分の緊急備蓄品リストを生成します。
- **印刷可能なカード**: オフラインでの学習やゲームに使えるカードをダウンロードできます。
- **災害対策ゲーム**: 組み込まれた「サイガイクン」ゲームを通じて楽しく学べます。
- **避難所マップ**: 越前市公式の避難所マップを閲覧できます。
- **アクセシビリティ**: 文字サイズや色合いを変更できます。
- **多言語対応**: 日本語と英語で利用可能です。

## 開発環境のセットアップ

[Nuxt.js](https://nuxtjs.org/)で構築されています。

```bash
# リポジトリをクローン
git clone https://github.com/code4fukui/fukui-bichiku-navi.git
cd fukui-bichiku-navi

# 依存関係をインストール
npm install

# 開発サーバーを起動（http://localhost:3000）
npm run dev

# 本番用にビルド（/docsに静的サイトを生成）
npm run generate
```
